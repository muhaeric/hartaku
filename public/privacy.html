💸 Hartaku

Kebijakan Privasi

Terakhir diperbarui: 4 Agustus 2026

Ringkasnya: Hartaku tidak punya database. Seluruh catatan keuanganmu disimpan di Google Spreadsheet di dalam Google Drive milikmu sendiri. Kami tidak menyimpan, membaca, maupun membagikan isinya.

1. Siapa kami

Hartaku adalah aplikasi pencatat keuangan pribadi berbasis web. Aplikasi ini dikembangkan sebagai proyek perorangan dan dipakai secara gratis. Dokumen ini menjelaskan data apa yang diproses aplikasi dan ke mana perginya.

2. Data yang kami proses

  • Identitas dasar Google: nama, alamat email, dan foto profil. Dipakai hanya untuk menampilkan siapa yang sedang masuk dan untuk menghubungkan sesi ke akun Google-mu.
  • Catatan keuangan — transaksi, akun, kategori, dan catatan investasi emas. Data ini tidak pernah dikirim ke server kami. Browser-mu menulisnya langsung ke Google Sheets memakai izin yang kamu berikan.
  • Token akses Google. Refresh token disimpan dalam bentuk terenkripsi (AES-256-GCM) di dalam cookie HttpOnly pada browser-mu. Server kami tidak menyimpan salinannya. Access token hanya hidup di memori halaman dan hilang saat tab ditutup.

3. Izin Google yang diminta

  • openid, email, profile — mengenali kamu saat masuk.
  • drive.file — membuat dan mengelola hanya file yang dibuat oleh aplikasi ini. Aplikasi tidak bisa melihat, membuka, atau menghapus file lain di Google Drive-mu. Ini adalah izin Drive tersempit yang tersedia.

Hartaku tidak meminta akses ke Gmail, Kontak, Kalender, atau layanan Google lainnya.

4. Penyimpanan di perangkatmu

  • Cache lokal. Salinan isi spreadsheet disimpan di localStorage browser agar aplikasi terbuka seketika tanpa menunggu jaringan. Cache ini tidak pernah dikirim ke mana pun, dan dihapus saat kamu keluar atau berganti spreadsheet.
  • Preferensi. Tema, mata uang, dan format tanggal disimpan lokal.

5. Fitur OCR (import dari screenshot)

Pembacaan teks dari screenshot berjalan sepenuhnya di perangkatmu memakai Tesseract. Gambar tidak diunggah ke server kami maupun ke layanan pihak ketiga, dan tidak disimpan setelah kamu meninggalkan halaman import.

6. Pihak ketiga

  • Google — autentikasi, Google Sheets, dan Google Drive. Tunduk pada Kebijakan Privasi Google.
  • Vercel — hosting. Menyimpan log permintaan teknis standar (alamat IP, waktu, user agent) untuk operasional dan keamanan.
  • logam-mulia-api — sumber harga emas harian. Dipanggil dari server kami, bukan dari browser-mu, dan permintaan itu tidak menyertakan data apa pun tentang kamu — hanya meminta harga hari ini.

7. Yang tidak kami lakukan

  • Tidak ada analytics, pixel pelacak, atau cookie iklan.
  • Tidak ada pelacakan lintas situs.
  • Tidak menjual, menyewakan, atau membagikan datamu ke siapa pun.
  • Tidak membaca isi spreadsheet-mu dari sisi server.

8. Retensi

Cookie sesi berlaku 7 hari dan diperpanjang setiap kali kamu membuka aplikasi. Jika aplikasi tidak dibuka selama 7 hari, sesi berakhir dan kamu perlu masuk lagi. Karena kami tidak menyimpan catatan keuanganmu, tidak ada data keuangan yang perlu kami hapus — kendalinya sepenuhnya ada padamu.

9. Mengontrol dan menghapus datamu

  • Cabut akses aplikasi: buka Izin akun Google, pilih Hartaku, lalu Hapus akses.
  • Hapus datamu: hapus spreadsheet bernama Hartaku - Expense Tracker dari Google Drive-mu. Datanya hilang seketika, karena hanya ada di sana.
  • Bersihkan perangkat: tombol Keluar di aplikasi menghapus cookie sesi dan cache lokal.

10. Anak-anak

Hartaku tidak ditujukan untuk pengguna di bawah 13 tahun dan tidak secara sengaja memproses data mereka.

11. Perubahan kebijakan

Kebijakan ini dapat diperbarui seiring berkembangnya aplikasi. Tanggal pembaruan terakhir selalu tercantum di bagian atas halaman ini.

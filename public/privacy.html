💸 Hartaku

Kebijakan Privasi

Terakhir diperbarui: 5 September 2026

Ringkasnya: Seluruh catatan keuanganmu disimpan di Google Spreadsheet di dalam Google Drive milikmu sendiri. Hartaku hanya menyimpan profil dasar Google dan waktu aktivitas untuk mengelola pengguna layanan; kami tidak menyimpan, membaca, maupun membagikan isi catatan keuanganmu.

1. Siapa kami

Hartaku adalah aplikasi pencatat keuangan pribadi berbasis web. Aplikasi ini dikembangkan sebagai proyek perorangan dan dipakai secara gratis. Dokumen ini menjelaskan data apa yang diproses aplikasi dan ke mana perginya.

2. Data yang kami proses

  • Identitas dasar Google: nama, alamat email, dan foto profil. Dipakai untuk menampilkan siapa yang sedang masuk, menghubungkan sesi ke akun Google-mu, serta menghitung dan mengelola pengguna layanan. Identitas ini disimpan di database Hartaku bersama waktu pertama masuk dan terakhir aktif.
  • Metadata aktivitas transaksi: waktu terakhir kamu berhasil menambahkan transaksi. Hartaku hanya menyimpan waktunya, bukan nominal, jenis, kategori, akun, deskripsi, atau isi transaksi lainnya.
  • Email operasional: saat pertama kali masuk, alamat email dan nama depanmu dipakai untuk mengirim email selamat datang. Admin Hartaku juga menerima pemberitahuan berisi nama, alamat email, dan waktu pendaftaranmu.
  • Catatan keuangan — transaksi, akun, kategori, dan catatan investasi emas. Data ini tidak pernah dikirim ke server kami. Browser-mu menulisnya langsung ke Google Sheets memakai izin yang kamu berikan.
  • Email notifikasi transaksi (opsional). Jika kamu mengaktifkan fitur Transaksi Otomatis (Beta), browser membaca email terbaru yang tampak seperti notifikasi transaksi bank atau e-wallet. Isi email diproses langsung di browser, tidak dikirim ke server Hartaku, dan tidak disimpan. Hanya hasil transaksi serta ID pesan untuk mencegah duplikasi yang ditulis ke spreadsheet milikmu.
  • Token akses Google. Refresh token disimpan dalam bentuk terenkripsi (AES-256-GCM) di dalam cookie HttpOnly pada browser-mu. Server kami tidak menyimpan salinannya. Access token hanya hidup di memori halaman dan hilang saat tab ditutup.

3. Izin Google yang diminta

  • openid, email, profile — mengenali kamu saat masuk.
  • drive.file — membuat dan mengelola hanya file yang dibuat oleh aplikasi ini. Aplikasi tidak bisa melihat, membuka, atau menghapus file lain di Google Drive-mu. Ini adalah izin Drive tersempit yang tersedia.
  • gmail.readonly — izin opsional dan baca-saja, diminta hanya ketika kamu memilih Hubungkan Gmail pada fitur Transaksi Otomatis. Dipakai untuk mencari dan membaca notifikasi transaksi; Hartaku tidak dapat mengirim, mengubah, maupun menghapus email.

Hartaku tidak meminta akses Gmail saat login biasa. Izin Gmail diminta secara terpisah hanya jika fitur opsional tersebut kamu hubungkan. Hartaku tidak meminta akses ke Kontak, Kalender, atau layanan Google lainnya.

4. Penyimpanan di perangkatmu

  • Cache lokal. Salinan isi spreadsheet disimpan di localStorage browser agar aplikasi terbuka seketika tanpa menunggu jaringan. Cache ini tidak pernah dikirim ke mana pun, dan dihapus saat kamu keluar atau berganti spreadsheet.
  • Preferensi. Tema, mata uang, format tanggal, pemetaan bank/e-wallet, status otomatisasi, serta waktu sinkronisasi terakhir disimpan lokal.

5. Fitur OCR (import dari screenshot)

Pembacaan teks dari screenshot berjalan sepenuhnya di perangkatmu memakai Tesseract. Gambar tidak diunggah ke server kami maupun ke layanan pihak ketiga, dan tidak disimpan setelah kamu meninggalkan halaman import.

6. Pihak ketiga

  • Google — autentikasi, Google Sheets, Google Drive, serta Gmail jika kamu mengaktifkan fitur opsional Transaksi Otomatis. Tunduk pada Kebijakan Privasi Google.
  • Vercel — hosting. Menyimpan log permintaan teknis standar (alamat IP, waktu, user agent) untuk operasional dan keamanan.
  • Neon — penyedia database PostgreSQL yang menyimpan profil dasar Google dan waktu aktivitas pengguna. Database ini tidak berisi catatan keuangan.
  • Resend — penyedia pengiriman email operasional. Nama dan alamat emailmu diproses untuk mengirim email selamat datang serta pemberitahuan user baru kepada admin Hartaku.
  • logam-mulia-api — sumber harga emas harian. Dipanggil dari server kami, bukan dari browser-mu, dan permintaan itu tidak menyertakan data apa pun tentang kamu — hanya meminta harga hari ini.

7. Yang tidak kami lakukan

  • Tidak ada pixel pelacak, profiling perilaku, atau cookie iklan.
  • Tidak ada pelacakan lintas situs.
  • Tidak menjual atau menyewakan datamu. Data hanya dibagikan kepada penyedia layanan yang disebutkan di atas sejauh diperlukan untuk menjalankan Hartaku.
  • Tidak membaca isi spreadsheet-mu dari sisi server.

8. Retensi

Cookie sesi berlaku 30 hari dan diperpanjang setiap kali kamu membuka aplikasi. Jika aplikasi tidak dibuka selama 30 hari, sesi berakhir dan kamu perlu masuk lagi. Profil dasar dan riwayat aktivitas akun disimpan selama akunmu masih tercatat sebagai pengguna Hartaku. Catatan keuangan tidak disimpan oleh Hartaku — kendalinya sepenuhnya ada padamu.

9. Mengontrol dan menghapus datamu

  • Cabut akses aplikasi: buka Izin akun Google, pilih Hartaku, lalu Hapus akses.
  • Hapus datamu: hapus spreadsheet bernama Hartaku - Expense Tracker dari Google Drive-mu. Datanya hilang seketika, karena hanya ada di sana.
  • Hapus profil Hartaku: kirim permintaan ke alamat kontak di bawah untuk menghapus profil dasar dan riwayat aktivitasmu dari database pengguna.
  • Bersihkan perangkat: tombol Keluar di aplikasi menghapus cookie sesi dan cache lokal.

10. Anak-anak

Hartaku tidak ditujukan untuk pengguna di bawah 13 tahun dan tidak secara sengaja memproses data mereka.

11. Perubahan kebijakan

Kebijakan ini dapat diperbarui seiring berkembangnya aplikasi. Tanggal pembaruan terakhir selalu tercantum di bagian atas halaman ini.
